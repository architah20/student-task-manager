# Student Task Manager

A web application that helps students manage their tasks, built with Python (Flask)
and delivered with a complete DevOps pipeline.

## Branching Strategy
- `main`: stable, release-ready code
- `develop`: integration branch for completed features
- `feature/STM-<ticket>-<name>`: one branch per Jira ticket

## Tools Used
Git, GitHub, Docker, Docker Compose, Jenkins, GitHub Actions, Jira, Prometheus,
Grafana, Terraform, AWS
